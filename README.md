# web-dev-practice-project-ideas

Below are simple web development projects for beginners to gradually understand web development 

# Project 1 (HTML, Nodejs)
1. Create a web page showing a heading "Hello, would you like to log in?" Login text would be an anchor link </a>, clicking on which the user will navigate to another page, which is the login page
2 Login page, is another page that has two input fields <input/> username and password, and also a submit <input type="submit" /> button
3 Clicking on that input button, validation would happen to determine  whether the username and password are correct
4 If incorrect show sorry password incorrect, please try again
5 If credentials are correct, showthe  login successful page, saying "Welcome, you are successfully logged in."
4 Internally, it would make an api request to the backend, and the backend would validate credentials and reply in response accordingly
